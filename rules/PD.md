# PR — Project Rules

## Objective
Maintain the approved KnowledgeGraph AI architecture and existing functionality.

## Mandatory Rules
1. Inspect the repository before modifying files.
2. Follow the existing folder structure and coding conventions.
3. Never overwrite unrelated user work.
4. Implement only the requested feature or phase.
5. Do not rewrite the entire application for a small change.
6. Do not add unnecessary dependencies, frameworks, or services.
7. Keep business logic separate from API routes and UI components.
8. Preserve existing functionality and API compatibility.
9. Never delete files, databases, volumes, or user data without explicit authorization.
10. Identify architecture conflicts before making major changes.

## Required Workflow
- Inspect relevant files.
- Identify affected modules.
- Make minimal, focused changes.
- Review the final diff.
- Report changed files and remaining work.

## Definition of Done
The requested feature works, existing functionality is preserved, and relevant checks have been performed.
