# DOCUMENTATION — Mandatory Documentation Rules

1. Keep README.md accurate and up to date.
2. Maintain .env.example whenever configuration changes.
3. Document Windows PowerShell installation and startup commands.
4. Document required Ollama models and local database setup.
5. Document API routes, schemas, and error responses.
6. Document database tables, graph schemas, and migrations.
7. Explain important architectural decisions and new dependencies.
8. Include reproducible testing commands.
9. Record known limitations and incomplete features.
10. Never document a feature as complete if it is only a placeholder.
11. Never claim a command or test was executed when it was not.
12. Never include passwords, tokens, secrets, or private document contents.

Update only the documentation relevant to the changes unless a broader update is requested.
